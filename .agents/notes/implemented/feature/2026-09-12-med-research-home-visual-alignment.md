# Med Research Home visual alignment

English | [中文](2026-09-12-med-research-home-visual-alignment.zh.md)

S01 Research Home now uses the supplied home prototype as its visual reference: a focused clinical hero, project creation prompt, project overview, metrics, and capability entry points. The view reserves bottom space for the host conversation composer so fixed host chrome cannot cover its content. Runtime CSS is embedded in the client bundle because the current client bundler does not load CSS module assets.
