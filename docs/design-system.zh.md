# DSH 产品设计系统

[English](design-system.md) | 中文

本参考定义 DSH 产品的外观与行为。[`web-styling.md`](web-styling.zh.md) 负责实现规则；实时取值来自 [`ui-theme`](../packages/client/ui-theme/README.zh.md) 的 `--dsw-*` 变量，可复用控件位于 [`ui-primitives`](../packages/client/ui-primitives/README.zh.md#component-catalog)。

## 产品特征

DSH 界面采用临床清晰度与证据可追溯性：高密度信息仍应易于扫描，重要状态带有明确文字，来源关系在视觉上强于装饰。蓝色标识导航、焦点、选择、链接和主操作；绿色、橙色和红色分别表达成功、需关注和失败。功能品牌可以增加范围狭窄的领域色，但不能替换产品交互色。

## 颜色角色

浅色调色板使用冷色画布（`#F7FAFF`）、白色表面、墨色文字（`#17233D`）、次级文字（`#5D6B85`）和蓝灰分隔线（`#E1E9F4`）。强调蓝为 `#287CF0`；承载文字的主操作使用更深的 `#216BD0`，悬停使用 `#195BB4`，低强调选择使用 `#EAF3FF`。

深色调色板使用 `#0F1115` 画布、`#151517` 与 `#232324` 表面、`#F9FAFB` 主文字、`#CFD3D6` 次级文字和 12% 白色分隔线。强调蓝为 `#75ADFA`；低强调选择使用 `#183E7A`。放在强调色填充上的前景一律读取 `--dsw-alias-label-on-accent`。

组件消费 `accent-primary`、`accent-strong`、`focus-ring`、`label-primary` 和 `state-*-label` 等语义别名，不消费原始调色板值，也不定义浅色/深色分支。

## 字体、间距与形状

产品 UI 使用平台系统无衬线字体栈。长篇论文阅读使用 `--dsw-font-reader-body`，即 17px/1.65 的衬线字体角色。间距遵循 4、8、12、16、24 和 32px 节奏，不增加间距 token 层。控件使用 8px 圆角，紧凑表面使用 12px，突出卡片使用 16px，只有胶囊控件使用完整圆角。平面表面使用边框；浮起表面使用两个产品 elevation 层级之一，不同时使用两者。

## 组件

功能包使用 `ui-primitives` 拼装控件。`Button` 提供 28、36 和 44px 三种高度，页面主操作使用 44px；`Input` 提供 32 和 40px 高度。`Field` 管理标签、辅助文字、错误关系和控件 ARIA 属性，调用方负责全部本地化文案。`TabList` 管理受控选择和漫游键盘焦点，调用方负责面板及其内容。

页面外壳、表格、卡片和领域可视化保留在功能包内，直到两个独立包需要相同行为。共享组件不含产品文案，也不依赖 Cordis。

## 响应式与无障碍行为

宽度不小于 1000px 时，工作台产品可以显示多列；700px 至 999px 时，次级区域移入抽屉；小于 700px 时，内容变为单列，主要区域通过标签切换。页面在 200% 缩放下仍须可用，不能出现整页横向滚动。

每个交互元素都具有可见键盘焦点、已本地化的无障碍名称；主操作的目标尺寸至少为 44px。标签列表支持左右、上下方向键以及 Home 和 End。状态不能只靠颜色表达。动画遵循 `prefers-reduced-motion`，移除动画时不能移除状态信息。

## 参考资产

`asset/` 下的文件是设计参考，不是运行时依赖。功能只能用真实应用状态复现其中的信息层级与关系；Reader、Statistics 或 Skills 行为尚未完成时，应呈现真实的空态、禁用态或不可用态，不能填入示例数据。
