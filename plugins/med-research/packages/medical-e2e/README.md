## Summary

Keyless end-to-end chains over the real services. `tests/research-chain.spec.ts` runs question -> recorded PubMed -> real JATS -> located evidence -> verified claim -> backend `[1]` citation.

## Known Limitations and Deferred Work

`tests/statistics-chain.spec.ts` covers the Statistics chain. The browser-visible UI chain is not covered here yet.
